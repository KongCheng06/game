# 箭头消消乐（赛博朋克风）

一个基于 pygame 的"点箭头消除"小游戏：点击棋盘上的箭头，若其前进方向（同一行/同一列）
到棋盘边界之间没有其他箭头阻挡，箭头就会飞出棋盘被消除；否则提示碰撞并消耗一次失误机会。
清除全部箭头即可过关，失误机会耗尽则本关失败。

## 玩法规则（基础版）

1. 棋盘是若干行 × 若干列的网格，部分格子中有一个单格箭头，方向为上 / 下 / 左 / 右。
2. 点击某个箭头后，程序沿其箭头方向检查到棋盘边界的路径（只判断同一行或同一列）：
   - 路径上没有其他箭头：该箭头飞出棋盘并被消除；
   - 路径上存在其他箭头：该箭头无法消除，通过"晃动 + 变红 + 文字提示"反馈碰撞，
     并消耗 1 次失误机会（阻挡它的箭头会高亮显示）。
3. 清除本关全部箭头即可进入下一关；失误机会用完则本关失败，可重新开始本关。

## 功能列表

- **关卡选择界面**：6 个固定关卡 + 无尽模式；通关后解锁下一关，可反复挑战刷新星级
- **星级评价**：按失误次数评 1~3 星（0 失误 = 3 星，1 次失误 = 2 星）
- **得分与计时**：每消除一个箭头 +100 分，每次碰撞 -30 分；每关单独计时
- **进度自动保存**：已解锁关卡、各关最好星级、无尽模式最高分自动保存到 `save.json`
  （与游戏/可执行文件同目录，删除该文件即重置进度）
- **提示功能**：每关 3 次，用金色脉冲光圈高亮一个可直接消除的安全箭头
- **撤销上一步**：恢复最近消除的箭头并扣回得分（碰撞失误不可撤销）
- **AI 自动求解**：贪心模拟消除顺序，自动 0 失误通关当前关卡（教学/演示用）
- **随机生成可通关的关卡**：所有关卡布局（含无尽模式）均由反向构造法生成，
  数学上保证存在 0 失误通关顺序，不会出现死局
- **动画与音效**：飞出缓动 + 拖尾残影 + 粒子光点、碰撞晃动变红、
  全部音效由正弦波实时合成（无需任何外部音频文件）
- **赛博朋克界面**：深色背景 + 霓虹光晕箭头与按钮

## 运行方法

需要 Python 3.8+ 和 pygame：

```bat
pip install pygame
python game.py
```

若音效无法播放（无声卡/驱动异常），游戏会自动静音运行，不影响玩法。

## 打包为可执行文件（Windows）

```bat
pip install pyinstaller
pyinstaller --onefile --noconsole --name ArrowGame game.py
```

生成的文件可拷贝到其他 Windows 电脑直接双击运行
（无需安装 Python）。存档文件会生成在 exe 同目录下。

## 关卡与难度

| 关卡 | 网格 | 箭头数 | 失误机会 | 布局缠绕度 |
|------|------|--------|----------|------------|
| 1    | 4×4  | 5      | 5        | 低         |
| 2    | 4×4  | 8      | 4        | 较低       |
| 3    | 5×5  | 10     | 4        | 中         |
| 4    | 5×5  | 13     | 3        | 中高       |
| 5    | 6×6  | 16     | 3        | 高         |
| 6    | 6×6  | 20     | 2        | 最高       |

无尽模式难度随层数持续递增（网格变大、箭头变密、失误机会变少、布局更缠绕），封顶后保持不变。
